ซ้อม rollout และกู้สถานะ session

ขั้น T9 สำหรับ operator/admin บันทึกการซ้อม L1–L3 ใน Core โดยไม่ส่ง MQTT หรือคำสั่งไปยังหุ่น และไม่เปิด feature flag

หากสร้างรายการแล้วเครือข่ายขาด ให้ค้นหา session ที่ยังเปิดอยู่ก่อนสร้างใหม่ แม้หุ่น offline หรือ permit หมดอายุก็ยังค้นหา session เพื่อปิดการซ้อมได้

สร้าง/เลื่อนระดับต้องมี permit ที่ใช้งานได้และตรงกับ operator/หุ่น ขอบเขตสูงสุด L3; Core ตรวจสิทธิ์และ revision ทุกครั้ง

ปิด session นี้ไม่ได้สั่ง STOP หุ่น ไม่ถอน permit ไม่ปิด flag และไม่คืน APK หากมีการเคลื่อนที่จริง ต้องให้ operator ดำเนินการ STOP และ rollback ภาคสนามตามขั้นตอนแยกต่างหาก
