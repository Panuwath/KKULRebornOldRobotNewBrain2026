ตรวจไฟล์ผลทดลองการเคลื่อนที่

ตรวจความครบถ้วนของหลักฐาน S5/T8 ในเบราว์เซอร์ ไฟล์ไม่ถูกอัปโหลดหรือบันทึกบนเซิร์ฟเวอร์ ผลตรวจไม่ใช่การรับรองความปลอดภัยหรืออนุญาตให้เคลื่อนที่

แต่ละระดับมี 4 ทิศทาง × 3 ครั้ง ใช้ความเร็วขนาดบวก: เดินหน้า/ถอยหลังเป็น m/s และหมุนซ้าย/ขวาเป็น °/s ระยะหยุดและระยะเกินเป้าหมายใช้ m สำหรับการเดิน และ ° สำหรับการหมุน ระบุเวลาเป็นมิลลิวินาทีบนฐานเวลาเดียวกัน พร้อมเครื่องมือ ผู้วัด ผู้สังเกตการณ์ และไฟล์หลักฐาน

result ใช้ PASS หรือ FAIL; sensor_ok, no_overlap, no_resume ใช้ true หรือ false; source_sha ใช้ Git SHA เต็ม 40 ตัว และ apk_sha256 ใช้ hash 64 ตัว

ยังไม่ได้เลือกไฟล์

    ค่าที่บันทึกยังต้องตรวจเทียบหลักฐานจริง ไม่คำนวณ p95 จากการทดลองเพียง 3 ครั้ง และรายงานนี้ไม่เปลี่ยน feature flag หรือ permit
